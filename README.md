# NIBM Data Engineering Fundamentals

This repository accompanies the NIBM HND Data Science data engineering module.
The practical branches build a local data platform using NYC Taxi and Limousine
Commission trip and zone data.

This branch contains the starter exercise for [Lecture 02 — ETL](docs/lectures/02-etl.md).
Start with [project and database setup](docs/setup.md), then review the
[dataset and cleaning contract](docs/datasets.md).

Lecture 01 is orientation. Each practical lecture uses a template and a complete
branch. In the course sequence, ETL leads into data modeling, incremental loading,
orchestration, distributed processing, data quality, governance and architecture.
Lecture 07 on streaming is deferred.
